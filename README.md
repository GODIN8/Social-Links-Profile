### What I learned

During this project, I improved my understanding of CSS Grid and responsive design, using media queries to adjust the layout for different screen sizes.

For example:

```css
@media (max-width: 375px) {
    .card {
        padding: 20px;
    }

    .name {
        font-size: 1.5rem;
    }
}
```
